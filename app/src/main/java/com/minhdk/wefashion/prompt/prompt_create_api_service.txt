Sau đây tao sẽ hưỡng dẫn mày tạo các thành phần của 1 remote API service.

1. Tạo nơi chứa các object responses và requests (chẳng hạn như request body) :
- Vào trong thư mục "infrastructure/model/api/" tạo mới 1 package có tên là loại đối tượng đó (ví dụ: account, user, order,...).
Bên trong package mới này, tạo 2 package con là request và response. Bên trong request sẽ là nơi tạo các object dành cho các
requests của api service định tạo, còn bên trong response sẽ là nơi tạo các object dành cho các responses của api service định tạo.
- Cách đặt tên object request và response:
Tên object request sẽ có dạng: Remote[Tên phương thức gọi API]Request
Tên object response sẽ có dạng: Remote[Tên phương thức gọi API]Response


2. Tạo nơi chứa interface api service:
- Vào trong thư mục "infrastructure/remote/dataService/" tạo mới 1 package có tên theo dạng: [Tên đối tượng]ApiService. Ở đây sẽ là nơi
khai báo các phương thức GET, POST, .... để gọi API. Tất cả các hàm đều dùng hàm suspend và trả về BaseResponse<Object response đã tạo>

3. Cuối cùng vào interface "infrastructure/remote/dataService/DataApiService" và thêm api service interface vừa tạo vào danh sách kế thừa
vì DataApiService sẽ là api service đại diện lớn nhất.
